One line of at most 200 characters for the
[make.fun](https://make.fun/c/u-alven-the-battery-s-last-text-to-its-charger-4278cfab)
"The Battery's Last Text to Its Charger" bounty: the phone battery's final
text message to the charger it waited for all day.

## The entry

> hey. it's me, your battery. 1%. i waited by the outlet all day and you never came. tell the wifi i loved it. don't let the flashlight see me like th—

The battery dies mid-word. That is the whole joke.

## Run it

Python 3, standard library only, no network, nothing to install:

```sh
python3 main.py
```

It writes the entry to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`).
